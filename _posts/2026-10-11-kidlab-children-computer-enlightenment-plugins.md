# 让电脑「开口说话」：我们给 DeepSeek Harness 做了一套儿童电脑启蒙插件

**关键词**：DeepSeek Harness、Cordis 插件、儿童编程启蒙、AI 智能体（Agent）、dsh-kidlab

> **核心结论**：「内存是什么？」「网络怎么把消息送过去？」——这些大人也讲不清的问题，我们把它做成了电脑上会动、能点、会说话的卡通卡片。孩子自己看一眼、点一下就能明白，家长一条命令就能装上。7 种电脑原理，被我们讲成了看得见的故事。

## 1. 背景：孩子的问题，常常把我们问住

家里的小朋友总爱追着问：「电脑为什么能记住东西？」「网上的消息是怎么跑过去的？」问题听着简单，解释起来却很难——因为内存、硬盘、进程这些东西，本来就藏在电脑里，看不见也摸不着。光靠嘴讲、靠画图，孩子很难有感觉。

我们团队平时做 AI 智能体（Agent）平台，天天和这些概念打交道。于是冒出一个念头：**能不能让电脑自己开口，用孩子听得懂的话讲清楚自己？** 与其我们费劲解释，不如把电脑里的原理做成一套能点、能跑、能看见的教具。

这个念头最后沉淀成了开源项目 dsh-kidlab。

## 2. 我们做了什么：七张会说话的卡片

dsh-kidlab 是给 DeepSeek Harness（一个基于 Cordis 插件框架搭建的 AI 智能体运行环境）写的一整套插件。每个插件都干两件事：给 AI 一个查询工具，再在对话框上方放一张卡通卡片。

卡片平时只占一行摘要，点一下才展开看明细；而且数据是真的实时读你自己的电脑，不是写死的示例。

| 插件 | 吉祥物 | 用哪个比喻讲什么 |
|---|---|---|
| kid-coder | 🐵 | 编程启蒙：真的把 Python 海龟画图跑起来 |
| kid-sysmon | 🐻 | 电脑体检：CPU、内存、磁盘、电池 |
| kid-network | 🕊️ | 网络 = 信鸽邮局（身份 / 送信 / 测速） |
| kid-storage | 🐿️ | 存储 = 电脑的大仓库（长期记忆） |
| kid-memory | 🦉 | 内存 = 电脑的工作台（短期记忆） |
| kid-security | 🐕 | 安全 = 城堡守卫 |
| kid-process | 🐝 | 进程 = 工作台上干活的小工人 |

**关键洞察**：我们刻意让比喻成体系——工作台（内存，短期）对着大仓库（存储，长期），小工人（进程）就在工作台上干活。孩子只要记住一套比喻，就能把整台电脑串起来理解，而不是记住七个互不相干的词。

顺带一提，每张卡片的用法和样子，我们在项目首页都放了真实录屏动图，不用安装就能一眼看懂。

## 3. 技术上，我们做了两个刻意的选择

**第一，一个包就是工具加卡片。** 我们让每个插件都是单包打包：一个包里同时装着给 AI 用的工具和给孩子看的卡片，纯 ESM、零构建，也不引用官方内部包。好处很直接——装一个插件像装一个 App 一样简单，不会牵一发动全身。

**第二，玩得开心，也要安全。** 孩子跑代码时，我们用沙箱隔离（sandbox），最多 8 秒自动叫停；读系统信息也全程不需要管理员（sudo）权限。让孩子放手试验，家长不用提心吊胆。

## 4. 怎么用上

七个包都已经发布到 npm 的 @kidlab 组织下，装法就一条命令。以编程启蒙那张卡为例：

dsh plugin --profile web add @kidlab/dsh-kid-coder

其余六个把结尾的名字换成 sysmon、network、storage、memory、security、process 即可。

首次装完重启一次 dsh web（让卡片进入客户端模块表），之后改内容只要刷新页面就行。

## 5. 结论与建议

- **核心发现**：把抽象的电脑原理做成能点、能看、会实时反应的卡片，孩子理解门槛会明显下降；让系统自己讲自己，比我们反复解释更有效。
- **给家长**：从 kid-coder（画图跑代码）和 kid-memory（工作台比喻）两张卡开始，孩子最快有「哇」的一声。
- **给做 Agent 的同行**：把系统信息做成卡片当教具，这套思路也能迁移到运维、教学、演示等场景，欢迎参考我们的单包打包写法。
- **下一步**：我们会继续加新主题（比如文件、时间、能源），也欢迎提问题、报 Bug、点个 Star。
