支付要验明「你是你」。用户名、密码、短信、银行卡，都是身外之物，要靠绑定关系间接认证；生物特征直接把「你本身」变成凭据。方便到什么程度，风险就到什么程度：脸每天露在街上，指纹每天留在杯子上，而泄露之后，密码可以改，脸不能。

§ 01

认证的尽头，是「你本人」

用户名、密码、短信、银行卡都能证明「某个人授权了这笔支付」，但它们证明的是你和那件东西的绑定关系。生物特征跳过绑定，直接拿你身上的生理或行为特点去比对。问题是：支付要的是「确认你是谁」，不是「从人海里把你找出来」。

身外之物卡、手机、用户名：丢了就换，借了就用 + 记忆与通道密码、短信、邮件：知道就能用，转发就泄露 + 生物特征脸、指纹、虹膜、声纹、掌纹、静脉：你走到哪带到哪 = 身份认证
凭证形态一串账号
泄露后能否重置能，改个名字
能否被复制能，记住就行
验证代价最低，几乎零成本
判定

用户名只回答「你说你是谁」，不回答「你真的是谁」。它必须再绑一个密码、一张卡或一段短信，才能变成一次可验证的授权。

MATCH MODE / 比对模式

支付做的是 1:1 确认，不是 1:N 找人

银行柜台核对身份证，是拿「你」和「你声称的那个人」比一次；从十万人里找一张脸，是另一件事。后者计算时间长、误配概率高，通常用于布控与检索，不用于单笔支付授权。

关键洞察：生物特征不是「更安全的密码」，而是「另一类凭证」。它省掉了携带与记忆，却把「泄露后不可重置」写进了系统前提；所以真正的设计问题不是「识别得准不准」，而是「识别错了、被冒用了，怎么兜底」。
§ 02

六把身体钥匙：读什么，怎么读

书里挑出六种有实践基础的生物特征：人脸、指纹、掌纹、静脉、声纹、虹膜。它们的差别不在「谁更高级」，而在采集什么信号、要不要接触、需不需要专用设备、能不能验活体。

SELECTED / B01

人脸

生理特征 · 面部轮廓

5个轮廓部位：眉、眼、鼻、口、颊

摄像头采集面部图像，计算机先定位人脸，再提取轮廓与特征点，最后和预留模板比对。支付场景只做一对一确认，不做一对多检索。

采集摄像头 / 视频
接触非接触
设备手机 / 收单平板
主要限制公开可采、不可重置
关键洞察：六种特征的「读取成本」差得很远。人脸和声纹用现成摄像头、麦克风就能采；虹膜、静脉、掌纹要专用设备。支付是高频低额场景，设备成本会直接决定它能不能铺开。
§ 03

一次刷脸，要过六道工序

「把脸对准摄像头」只是一个动作，背后是采集、检测、预处理、特征提取、匹配、识别六步。任何一步出问题，结果都不是「支付失败」这么简单：可能是该过的人没过，也可能是别人过了。

STEP 01 / CAPTURE

采集：先把脸变成像素

摄像头（CCD 或 CMOS 传感器）把光学信息转成数字图像。CCD 分辨率高但能耗约为 CMOS 的 100 倍，今天手机与收单设备基本都用 CMOS。

这一步失败会怎样光线太暗、角度太偏，后面再准也没有可用的输入
AUTH MODE / 刷脸到底顶了什么

刷脸 = 输入用户名；小额可以免密，大额还得加密码

01刷脸相当于输入用户名
02密码 / PIN大额时才需要
03扣款账户扣减并通知

小额免密不是「刷脸就绝对安全」，而是金额小、风控赔得起：用限额把单次风险封顶，再用行为模型盯异常。

关键洞察：六步里只有第五步在「比对」，前四步都在「把脸变成可比的东西」。绝大多数现场失败不是算法不认识你，而是光、角度、遮挡、分辨率让输入根本不合格。
§ 04

钥匙不能换：所以要多配一把锁

密码泄露了可以改，卡丢了可以挂失；人脸泄露了，不能靠改密码解决，理论上只能做换脸手术。生物特征支付因此天然需要第二个因子：不是不信任识别技术，而是给「不可重置」这件事兜底。

PASSWORD / 密码

泄露 → 改一条记录

恢复动作改密码
恢复时间1 分钟
恢复成本≈ 0

凭证与人是分离的：换掉凭证，人不受影响。

FACE / 人脸

泄露 → 换一张脸

恢复动作外科手术
恢复时间以月计
恢复成本不可接受

凭证与人是同一个：换掉凭证，等于换掉人。

2FA / 双因子

再加一个可重置的因子

典型组合人脸 + 密码

攻击门槛同时拿下两条

生物特征负责「你本人」，密码/短信/eID 负责「可撤销的授权」。

2FA BUILDER / 组合两个因子

双因子的关键，是两个因子「不同类」

人脸 + 指纹都还是「你身上的一部分」；人脸 + 密码才是「你本人 + 你知道的东西」。多因子（MFA）逻辑相同，只是叠得更多、更安全，也更麻烦。

攻击者需要同时具备 一张活人脸 + 正确密码 用户额外耗时 约 8 秒 安全等级 L2 / 中高

判定

人脸 + 密码：一条生物因子 + 一条可撤销因子。攻击者要同时拿到活人脸和密码，门槛明显高于单刷脸。

关键洞察：双因子不是「多一道验证」，而是「多一条独立的攻击路径」。如果两个因子能被同一次攻击一起拿下——比如手机丢了、密码也在手机里——那只是把两道门装在了同一个门框上。eID 的价值就在这里：它把核验放到公安部门的人口库，支付机构手里不存那份底账。
§ 05

指纹：三种纹型，四种读法

指纹是最早普及的生物识别，也是手机里最常见的一种。它由「嵴」和「峪」构成：凸起的脊线、凹下的谷线。识别不是拍照存图，而是把纹路变成特征点；采集技术不同，速度、体积、成本、清洁要求就不同。

WHORL / 斗型
嵴 / 凸起的脊线 峪 / 凹下的谷线

关键洞察：指纹支付的瓶颈不在算法，在「接触」。接触带来卫生顾虑、设备磨损、老人指纹磨平、杯子和门把手上留痕；所以它在手机解锁里赢了，却没能在线下收单里铺开。技术排名低，不等于技术差。
§ 06

越看得见，越好采；越内藏，越难偷

把六种特征放在一张图上：横轴是「要不要接触设备」，纵轴是「特征外显还是内藏」。左上角是方便与风险的交汇处——人脸、声纹；右下角是安全与成本的交汇处——静脉、指纹。没有一种特征同时拿到四个角。

关键洞察：「非接触」不等于「安全」，「内藏」也不等于「方便」。人脸赢在自然，输在不可重置；静脉赢在活体与内藏，输在必须把手指伸进设备。支付选型就是在这些性质之间做交换，而不是找一把全能钥匙。
§ 07

换一个维度，冠军就换人

书里的横向比较给了一个明确结论：刷脸最好，掌纹第二，指纹总分最低。但这个「最好」是按自然、方便、卫生、安全、接受度综合出来的；把维度一换，静脉、声纹、虹膜都可能冒头。

§ 08

精度不是一个数，是一对跷跷板

「准确率 99%」这句话在生物识别里几乎没用。真正要问的是：把坏人放进来的概率是多少（FAR），把好人挡在外面的概率是多少（FRR）。这两个数由同一个阈值控制，一个降，另一个就升。

样本库300枚100 人 × 右手食指 3 次
两两比对89,700次300 × 299
同指真匹配600次100 人 × 6 组合
书中阈值90%相似度门槛
FAR / FRR · 阈值滑杆
平衡区
FAR / 误识率：把该拒的放进来 FRR / 拒识率：把该过的挡在外 EER：两条线的交点

CONFUSION / 四种结果

真阳、真阴、假阳、假阴

把「有病 / 没病」换成「本人 / 冒用者」，四个格子就是风控的全部结局。TPR = TP / (TP + FN)，FPR = FP / (FP + TN)。

TP真阳

本人，且判定为本人

该放行的放行了
FP假阳

冒用者，却判定为本人

该拦的放进来了 → 资金损失
FN假阴

本人，却判定为冒用者

该放的挡在外 → 体验损失
TN真阴

冒用者，且判定为冒用者

该拦的拦住了
FAR = NFA / NIRA  ·  FRR = NFR / NGRA  ·  TPR = TP / (TP + FN)  ·  FPR = FP / (FP + TN)
关键洞察：调阈值不是「提高精度」，而是「选择把损失放在哪一边」。调严，钱更安全，但更多真人被挡在门外；调松，通过率更高，但更多冒用者被放进来。EER 只是两条曲线交点，它告诉你算法在哪个点最平衡，不告诉你该用哪个点——那要由单笔金额、赔付能力、用户体验共同决定。
§ 09

选一把钥匙，先看四个约束

没有「最好的生物特征」，只有「在这个场景里最合适的组合」。先问四件事：金额多大、要不要接触、有没有专用设备、能不能接受被拒。答案不同，钥匙就不同。

§ 10

收口：六把钥匙，四层可能被偷的地方

第 1 章按时间列环节，第 2 章按模式列结构，第 3 章按载体列层级，这一章按「采集 → 模板 → 比对 → 授权」列生物特征的风险。同一种风险换一把钥匙不会消失，只会换一层发生。

采集层

样本被采走

可获取样本数 × 合成质量

脸在街上、指纹在杯子上、声纹在短视频里。采集这一层最便宜，所以冒用成本也最低。

模板层

模板不可重置

模板条数 × 跨场景复用度

库里存的是特征不是照片，但它不能改。泄露一次，十年都要用同一条模板。

比对层

阈值就是损失选择

阈值 × FAR / FRR

调严挡冒用也挡真人，调松通过率高也放进来。阈值不是技术参数，是业务决策。

授权层

单因子扛不住大额

单笔限额 × 是否双因子

只用一条不可撤销的因子授权大额，等于把损失上限交给了算法。

关键洞察：生物特征的风险不在「认不准」，而在「认准了也证明不了本人意愿」。FAR/FRR 解决的是「像不像」，双因子与金额分层解决的才是「谁授权、授权到多少」。四层里越靠下（授权、合规），出事越贵，也越不能靠算法兜底。
Q01
为什么书里说刷脸支付可以做，但支付场景大多只做一对一确认？
一对一确认回答的是「你是不是你声称的那个人」，计算量小、阈值可控；一对多检索要从海量库里找人，计算时间长、误配概率高，适合布控与检索，不适合单笔授权。支付要的是确定性，不是「最像」。
Q02
刷脸已经识别出本人了，为什么大额还要输密码？
因为人脸是公开可采、不可重置的凭证。大额交易不能只靠一条不可撤销的因子；密码或 eID 是第二条独立路径，负责「授权可撤销」这件事。小额免密则是用限额把单次损失封顶，不是把风险归零。
Q03
FAR 和 FRR 能不能一起降？
在同一个算法上，它们由同一个阈值控制：阈值调严，FAR 降、FRR 升；调松，反过来。要同时降，只能换更好的算法（把整条曲线下移），这也是 EER 用来比较算法整体性能的原因。
Q04
指纹识别技术很成熟，为什么在书里的六种支付中总分最低？
因为支付不只看识别率。指纹要接触设备，带来卫生顾虑与设备磨损；手指每天接触大量物品，留痕与信息泄露风险高；老年人指纹磨平，识别率下降。它在手机解锁场景赢，是因为设备本来就在手里；线下收单要额外铺设备，动力不足。
RULE 01

先问凭证能不能重置。不能重置的因子，不能单独承担大额授权；必须配一个可撤销的第二因子。

RULE 02

先问采集是不是接触。接触决定卫生、磨损、老人可用性，也决定设备成本落在谁头上。

RULE 03

先问阈值把损失放在哪边。调严保护资金、牺牲通过率；调松反过来。阈值是业务决策，不是技术参数。

RULE 04

模板不可逆，比加密更靠得住。密钥泄露可以换，模板泄露换不了；存特征、不存原图，按场景隔离，用令牌代替裸模板。

RULE 05

活体检测是持续攻防，不是一次验收。方案要版本化、要回归、要吃进攻击样本；只做一次活体就等于给攻击者留时间窗。

RULE 06

大额永远不靠单因子。不可撤销的因子只承担「你是你」，金额与意愿必须由可撤销的第二条路径来锁。
